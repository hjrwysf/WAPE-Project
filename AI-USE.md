# AI Usage Documentation

## 1. AI Tool Used

- **Tool:** ChatGPT
- **Purpose:** Learning assistance, code guidance, implementation support, debugging, and documentation.

## 2. How AI Was Used

ChatGPT was used during the development of the Movies Web Application to support the implementation and understanding of the React frontend.

The main uses included:

- **React Development:** Assistance with creating React components and understanding component structure.
- **Mock Data:** Guidance on preparing movie records using JavaScript objects and arrays.
- **React State Management:** Assistance with using `useState` to manage movie data, search terms, selected genres, and sorting options.
- **Props:** Guidance on passing data and functions between React components.
- **Search and Filtering:** Assistance with implementing movie search and genre filtering using JavaScript `filter()`.
- **Sorting:** Guidance on implementing movie sorting by rating and release year using `sort()`.
- **CSS Styling:** Assistance with styling movie cards, filtering controls, and the main page.
- **Image Troubleshooting:** Assistance with identifying and replacing broken movie poster image links.
- **Git and GitHub:** Step-by-step guidance on staging, committing, and pushing project files.
