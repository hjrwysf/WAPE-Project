# WAPE Project

## Project Overview

A Full-Stack MERN Web Application developed as part of the Web Applications Programming and Engineering (WAPE) course.

The application is designed to provide users with an interactive platform to browse and manage movie information.

## Technologies

- **Frontend:** React, JavaScript, CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB, Mongoose
- **Version Control:** Git and GitHub

## Implemented Features

### Frontend

- React main page.
- Movie mock data containing 30 movie records.
- Reusable MovieCard and MovieList components.
- Search movies by title.
- Filter movies by genre.
- Sort movies by rating and release year.
- Combined search, filtering, and sorting.
- Responsive layout for desktop and mobile screens.

## How to Run the Frontend

### Prerequisites

- Node.js
- npm

### Installation

1. Navigate to the client directory:

```
cd client
```

2. Install dependencies:

```
npm install
```

3. Start the development server:

```
npm run dev
```

4. Open the local URL displayed in the terminal, usually:

```
http://localhost:5173/
```
